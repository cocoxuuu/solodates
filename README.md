# Solo Date Jar

A jar of 50 solo date ideas. Press the jar to draw a date, save it for later, and keep a diary of the dates you've been on: what you did, how you felt, and how many hearts you'd give it.

Created by coco xu.

## Run it

It's a single file. Open `index.html` in a browser, or publish it with GitHub Pages (Settings → Pages → deploy from the `main` branch).

Outside claude.ai, diary entries are saved in the visitor's own browser.
